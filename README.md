# ハエの協奏曲（試作 ver1）

ハエの大群を動かして机の上のものを食べ、増えていく様子と重なる羽音を味わう、静かな放置系ブラウザゲームの試作です。

## 遊ぶ
- **ブラウザで遊ぶ**: https://jinkinokino5-max.github.io/hae-no-kyousoukyoku/
- **手元で遊ぶ（Windows）**: このフォルダの `起動.bat` をダブルクリック（Python が必要）。
  - 他の環境では、このフォルダで `python -m http.server 8765` を実行し、http://localhost:8765/ を開く。

## 操作
- 画面をクリックすると、カーソルが画面の中に固定されます（**Esc で解除**）。
- カーソルを動かすと、ハエの群れがついてきます。画面の縁に押し当て続けると、机の上をどこまでも飛んでいけます。
- 机の上のものに群れが触れると、少しずつ食べてハエが増えます。食べたものによって何かが起こります。
- 最初のクリックで音も鳴り始めます。
- 1,000匹になると、幕が閉じます。

テスト用キー: `D` デバッグ表示 / `N` ハエ +100匹

## 技術
- 外部素材なし。絵（ピクセルアート）と音（羽音・曲）はすべてコードで生成しています（Canvas / Web Audio）。
- 終幕の曲は「蛍の光」（スコットランド民謡 Auld Lang Syne、パブリックドメイン）を合成しています。
