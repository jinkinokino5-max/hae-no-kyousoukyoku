# ハエの協奏曲（試作 ver1）

ハエの大群を動かして机の上のものを食べ、増えていく様子と重なる羽音を味わう、静かな放置系ブラウザゲームの試作です。

## 遊ぶ
- **ブラウザで遊ぶ**: https://jinkinokino5-max.github.io/hae-no-kyousoukyoku/ （タイトル画面で「ふつうの版」「音楽版」を選べます）
- **音楽版**（食べたモノごとに有名曲が流れる派生版）: https://jinkinokino5-max.github.io/hae-no-kyousoukyoku/ongaku/
- **手元で遊ぶ（Windows）**: このフォルダの `起動.bat` をダブルクリック（Python が必要）。
  - 他の環境では、このフォルダで `python -m http.server 8765` を実行し、http://localhost:8765/ を開く。

## 操作
- 画面をクリックすると、カーソルが画面の中に固定されます（**Esc で解除**）。
- カーソルを動かすと、ハエの群れがついてきます。画面の縁に押し当て続けると、机の上をどこまでも飛んでいけます。
- 机は上下左右どこまでも続いています。モノは場所ごとにランダムに置かれています（画面の縁のかすかな点が、近くのモノの方向です）。
- 机の上のものに群れが触れると、少しずつ食べてハエが増えます。食べたものによって何かが起こります（全24種）。
  - 食べ物: バナナ、麻婆豆腐、角砂糖、食パン、りんご、寿司、ショートケーキ、コーヒー、梅干し、スイカ、唐辛子、おにぎり
  - 文化物: レコード、漫画、ラジオ、万年筆、楽譜、オルゴール、置き時計、風鈴、ろうそく、絵の具、トランプ、電球
- レコードはラベルの色ごとに違う曲が流れ、羽音がその和音に溶けていきます（全8曲: ジムノペディ、エリーゼのために、グリーンスリーブス、ブラームスの子守歌、メヌエット ト長調、歓喜の歌、カノン、オリジナルのワルツ）。
- 最初のクリックで音も鳴り始めます。
- 食べると群れが何倍にも増え、放っておいても少しずつ増殖します。ハエが画面いっぱい（4万匹）になると、幕が閉じます。

テスト用キー: `D` デバッグ表示 / `N` ハエ ×1.5倍

## 技術
- 外部素材なし。絵（ピクセルアート）と音（羽音・曲）はすべてコードで生成しています（Canvas / Web Audio）。
- 曲はすべて著作権の切れた作品・伝承曲（またはオリジナル）を、記憶から書き起こして合成しています。終幕の曲は「蛍の光」（スコットランド民謡 Auld Lang Syne）。
